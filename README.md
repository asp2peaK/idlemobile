# 🎲 Кости Судьбы

Мобильная idle-игра в духе D&D: ведёшь отряд героев вниз по подземелью, и каждый удар — это бросок кубика.
Чистый HTML/CSS/JS, без сборки.

## Как запустить

```bash
python3 -m http.server 8000
# компьютер: http://localhost:8000
# телефон в той же Wi‑Fi: http://<IP-компьютера>:8000
```

Или просто открой `index.html`. В Chrome DevTools включи режим устройства (Ctrl+Shift+M).

## Механики

- **Бросок атаки d20 против КД.** У монстра есть класс доспеха (КД). Попадание: `d20 + бонус ≥ КД`.
  **Нат. 20** — всегда попадание и крит (урон ×2), **нат. 1** — всегда промах.
- **Тап** по монстру или по большому d20 — твой личный удар. Персонаж качается во вкладке «Герой»:
  Сила, Кубик урона (d4 → d6 → … → 8d20), Точность, Тактика.
- **Отряд из 10 классов** со своими кубиками и особенностями:
  | Класс | Кубик | Особенность |
  |---|---|---|
  | ⚔️ Воин | d10 | +3 к попаданию |
  | 🗡️ Плут | 2d4 | крит на 19–20, урон ×3 |
  | 🏹 Следопыт | d8 | +6 к попаданию |
  | ☀️ Жрец | d6 | +2% золота за уровень |
  | 🧙 Волшебник | d12 | всегда попадает |
  | 🛡️ Паладин | d10 | крит ×4 |
  | 🪕 Бард | d6 | +1% урона всему отряду за уровень |
  | 🪓 Варвар | d12 | всегда бросает с преимуществом |
  | 🐻 Друид | 3d8 | — |
  | 👁️ Колдун | d20 | крит на 18–20 |

  Уровни 10, 25, 50, 75… удваивают урон героя.
- **Этажи и биомы:** Подземелье → Тёмный лес → Склепы → Огненные пещеры → Ледяной пик → Бездна, дальше они идут по новому кругу с приставками «Древний», «Проклятый»…
  10 монстров на этаж, каждый 5-й этаж — **босс с таймером 30 сек**.
- **Умения:** 🔥 Ярость (урон ×2), 🍀 Преимущество (2d20, берётся лучший), 💰 Мидас (золото ×3).
- **Сундук** — проверка удачи d20: от горсти монет до сокровищ дракона на нат. 20… или **мимик** на нат. 1.
- **Новая кампания** (престиж с 20-го этажа) — Осколки Судьбы, +10% к урону и золоту навсегда.
- Офлайн-доход до 8 часов, автосохранение.

## Планы

1. **Лут и экипировка** — с монстров падают предметы (+1 меч, плащ эльфов), редкость определяется броском
2. **Реликвии за осколки** — дерево перков вместо простого +10%
3. **Расы героев** (эльф, дварф, полурослик) с бонусами к броскам
4. **Заклинания с ячейками**, которые восстанавливаются после «длинного отдыха»
5. **Квесты таверны** — отправить героя на задание на N минут
6. **Звуки** — стук кубиков, музыка таверны
7. **PWA**, чтобы ставить на главный экран, а потом сборка через Capacitor для Google Play / App Store
