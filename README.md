# 🎲 Кости Судьбы

Мобильная idle-игра в духе D&D: отряд героев спускается в бесконечное подземелье, каждый удар — бросок кубика,
с монстров падает лут. Весь арт нарисован в коде (SVG), монстры собираются процедурно.

**Стек:** Vite + React 19 + motion (анимации).

## Играть без установки

Скачай **`kosti-sudby.html`** и открой его в браузере (на телефоне — через «Файлы» / «Загрузки» → открыть в Chrome/Safari).
Ничего ставить не нужно, всё внутри одного файла. Без интернета игра тоже работает, только шрифты будут системные.
Прогресс сохраняется в браузере.

Пересобрать этот файл: `npm run build:single`.

## Запуск для разработки

```bash
npm install
npm run dev        # http://localhost:5173, с телефона в той же Wi‑Fi — http://<IP-компа>:5173
npm run build      # сборка в dist/
```

Галерея всего арта (монстры, предметы, иконки): http://localhost:5173/gallery.html

## Что нового в 2.0

- **Монстры бьют в ответ.** У отряда есть ХП и КД, монстры атакуют броском d20 против КД отряда. Отряд может пасть — тогда отступает на этаж и отдыхает.
  Жрец и друид лечат, паладин поднимает КД, варвар даёт ХП.
- **Мощные удары и блок.** Монстр замахивается (красная полоса) — жми «БЛОК»: спасбросок d20 против Сложности. Успех — враг оглушён и следующий тап крит.
- **Слабые места.** На монстре вспыхивает руна — попади по ней, и удар будет ×5, а монстр станет уязвимым.
- **Свойства монстров:** Бронированный, Регенерация, Неистовый, Призрачный, Вампир, Шипастый, Громила, Увёртливый.
- **Уровень персонажа и таланты:** 3 ветви (Воитель, Страж, Ловкач), сбрасываются каждую кампанию.
- **Таверна:** доска контрактов с наградами (пыль, вещи, золото, иногда осколки).
- **Новая кампания:** снаряжение сгорает, кроме фамильных вещей; пыль — наполовину. Можно взять проклятия ради бонуса к осколкам.
- **Баланс:** прогресс примерно в 4 раза медленнее, осколков меньше, реликвии дороже, лут слабее.

## Механики

- **Бросок атаки d20 против КД.** Нат. 20 — крит, нат. 1 — промах. Тапай по монстру или по d20.
- **Отряд из 10 классов** со своими кубиками и перками (плут критует на 19–20, волшебник всегда попадает, варвар бросает с преимуществом…).
  Уровни 10/25/50/75/100/150… удваивают урон. Плюс **3 тайных героя**, которые открываются на 60, 100 и 160 этажах.
- **Бесконечное подземелье:** 10 биомов по 10 этажей (Подземелье → Тёмный лес → Склепы → Гнилые топи → Огненные пещеры →
  Ледяной пик → Руины пустыни → Небесная цитадель → Бездна → Астрал), потом новый **Круг** — те же земли, но злее.
  Каждый 5-й этаж — вожак, 10-й — босс биома с короной, 50-й — Великий босс.
- **Процедурные монстры:** 11 архетипов (слизень, гоблин, череп, волколак, око, паук, призрак, голем, демон, нетопырь, дракон)
  + мимик. Цвет, глаза, рога, шипы, шрамы, ауры и имена боссов генерируются.

### Лут и экипировка
- 6 слотов: оружие, шлем, доспех, амулет, кольцо, сапоги.
- **Редкость решает бросок d20 + удача:** обычный → необычный → редкий → эпический → легендарный (нат. 20) → **мифический** (нат. 20 + подтверждение).
- Случайные свойства: урон, урон тапа/отряда, золото, крит. урон, скорость, попадание, диапазон крита, удача, шанс лута, таймер босса, бонус конкретному классу.
- **12 легендарных свойств** (Ворпальный клинок, Кольцо эха, Семимильные сапоги…) — собираются в Кодексе.
- **Заточка** за пыль: бросок d20 против Сложности, бесконечно (+8% за уровень). Провал — пыль сгорает, предмет цел.
- Разбор в пыль, авторазбор по редкости, защита предметов, сравнение с надетым.

### Долгая игра
- **Новая кампания** (с 20-го этажа) → Осколки Судьбы → **9 реликвий**, часть с бесконечными уровнями. Экипировка и пыль сохраняются.
- Умения: Ярость, Преимущество, Мидас. Сундуки с проверкой удачи (и мимиками).
- **Кодекс:** атлас земель, коллекция легендарок, хроника.
- Офлайн-доход и офлайн-лут до 8 часов.
