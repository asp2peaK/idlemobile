# 🏰 Королевство Idle

Средневековая idle-игра (кликер) для мобилки. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Как запустить

Самое простое — открыть `index.html` в браузере.

Или через локальный сервер (удобно, чтобы открыть с телефона в той же Wi‑Fi сети):

```bash
python3 -m http.server 8000
# компьютер: http://localhost:8000
# телефон:   http://<IP-компьютера>:8000
```

В Chrome DevTools включи режим устройства (Ctrl+Shift+M), чтобы смотреть как на телефоне.

## Что уже есть (v0.1)

- **Тап по замку** — сбор налогов, всплывающие цифры, вибрация на телефоне
- **10 построек**: Крестьянин → Ферма → Лесопилка → Каменоломня → Кузница → Рынок → Таверна → Собор → Замок → Логово дракона. Цена растёт ×1.15 за штуку, покупка ×1 / ×10 / Макс
- **Улучшения**: ×2 к постройке на 10/25/50/100/150 шт., усиления тапа, глобальные бонусы к доходу
- **Странствующий купец** 🧳 — иногда появляется на 12 сек: сундук с золотом, «Праздник урожая» (доход ×5) или «Боевой клич» (тап ×15)
- **Престиж «Новая династия»** — передаёшь трон, получаешь короны 👑 (+10% к доходу навсегда за каждую)
- **Офлайн-доход** до 8 часов
- **Автосохранение** в localStorage каждые 5 сек и при сворачивании
